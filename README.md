# ATM Machine Project

## About the Project
This is a simple ATM Machine project developed as part of the Full Stack Python Development training conducted by Fynd.

The project helps me understand the basic working of an ATM machine using programming.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Simple menu to select options

## Technologies Used
- Python

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the Python file.
4. Follow the instructions shown on the screen.
